Your data

Privacy Policy

Last updated 22 November 2026. The short version: the website code never uploads your files, and it does not set cookies or run analytics.

The short version

  • Your video, image and SRT text stay inside your browser tab.
  • There is no account, database, upload endpoint or contact form on the site.
  • The site does not use advertising scripts, analytics tags or tracking cookies.
  • Closing the tab clears the in-memory file references. You can also use the Clear buttons.

What happens when you check a file

When you choose a video or image, the browser creates a local object URL for that file. The preview element reads it so the page can measure width, height, duration and size. No request is sent to a ClipCheck server because no such server exists. The URL is released when you clear the file, choose another file or leave the page.

The transparent PNG generator draws into a canvas in your browser and downloads the result directly. It does not send the image anywhere. Likewise, the safe-area guide is calculated from a small set of percentages stored in the site's JavaScript.

What happens to subtitle text

Pasted SRT text and subtitle files are read as plain text and parsed by JavaScript on the page. The validator produces a report in your browser. Nothing is stored in local storage, session storage or a cookie, and there is no history of previous checks.

Cookies, analytics and trackers

ClipCheck Studio does not set cookies and does not include third-party tracking or advertising code. The page loads only its own stylesheet and script. That is why the tools still work after the initial page load, even if your connection drops.

Hosting and ordinary network logs

The site is hosted free on GitHub Pages. Requesting any web page involves network metadata such as an IP address and a timestamp, and the hosting provider may keep standard operational logs under its own policies. ClipCheck Studio itself does not read, store or process those logs. If you need details about the host's practices, consult GitHub's privacy documentation.

Links to other sites

The contact page links to the project's public issue tracker on GitHub. If you follow that link, GitHub's own terms and privacy policy apply. The site also names TikTok, Instagram and YouTube as format references; those names are not links to third-party trackers and do not imply a relationship.

Children's privacy

This is a general utility tool and is not directed at children under 13. It does not knowingly collect personal information from anyone.

Changes and questions

If this policy changes, the update date at the top will change with it. Because the application holds no personal data, there is no account to delete and no stored file to remove. Questions can be raised through the contact page.
